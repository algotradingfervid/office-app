Orange palettes for Placet

Same mark, type and layout; only the colours change. Each screen shows the mark, a link ("Requests"), a highlighted row, an error, the main button and the keyboard focus ring (on "Cancel"). Every text colour passes WCAG AA (4.5:1). Statuses carry a word and a symbol as well as a colour. So statuses never look like the brand colour: Pending is slate grey-blue, Rejected is a cool berry red, and Approved stays a small green word.

1 · Burnt orange & graphite

A deep, fired orange with charcoal. Warm and confident, still clearly a work tool.

Buttons: white on #B4470E (5.46:1). Links and small orange text use the same colour (4.89:1 on paper).

2 · Fervid family orange

Matches Fervid Smart's own orange #DA4F27, so Placet reads as a Fervid product.

Fervid's exact orange is too light for text or white-on-orange buttons (4.09:1, fails AA). It is used for the mark and large fills; buttons and links use a darker text-safe version, #B83F1C (5.58:1).

3 · Saffron & charcoal

Bright saffron as a fill, with dark ink text on it. Distinctly Indian, energetic but tidy.

Saffron is too light for white text, so buttons carry dark ink on saffron (6.15:1). Links use a deep saffron-brown, #9A4A00 (5.61:1).
